# 🐍 贪吃蛇小游戏 (Snake Game)

一个纯前端实现的经典贪吃蛇小游戏：**HTML + CSS + 原生 JavaScript**，无需任何构建工具与依赖，双击 `index.html` 即可游玩。

在线体验：打开 [GitHub Pages](https://maning77.github.io/snake-game/)（如已启用）或直接本地运行。

---

## 🎮 玩法

- 使用 **方向键** 或 **WASD** 控制蛇的移动
- 吃到红色苹果：蛇身增长，**+10 分**
- 撞到墙壁或自己的身体：游戏结束
- 手机端：使用屏幕上的方向键按钮，或在棋盘上**滑动**控制

## ✨ 功能特性

| 功能 | 说明 |
| --- | --- |
| 最高分记录 | 通过 `localStorage` 本地持久化，刷新页面不丢失 |
| 暂停 / 继续 | 按 `空格` / `P` 随时暂停 |
| 自动提速 | 每得 50 分，游戏速度提升一档（难度递增，越玩越刺激） |
| 触屏支持 | 方向按钮 + 滑动手势，手机可玩 |
| 动效视觉 | 蛇头眼睛朝向、苹果呼吸动画、失败红闪 |
| 结束界面 | 友好的 Game Over / 胜利覆盖层，一键重开 |
