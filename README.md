# 🐍 贪吃蛇小游戏

一个用 **HTML + CSS + 原生 JavaScript** 实现的经典贪吃蛇游戏，零依赖、零构建、双击 `index.html` 即可玩。

## ✨ 功能特性

### 核心玩法
- 20×20 网格 Canvas 渲染
- 方向键 / WASD 移动（禁止 180° 直接掉头）
- 随机食物生成（自动避开蛇身）
- 吃食物 +10 分，蛇身增长
- 撞墙 / 撞自身判定游戏结束
- 填满棋盘触发胜利

### 体验增强
- ⏸ **暂停 / 继续**：空格、P 或屏幕按钮
- 🏆 **最高分**：自动 `localStorage` 保存
- 🚀 **难度递增**：每得一定分数自动提速（难度不同节奏不同）
- 📱 **移动端**：方向键按钮 + 棋盘滑动手势
- 🎮 **音效**：Web Audio API，吃食物 / 升级 / 失败 / 暂停都有反馈音
- 🔊 **静音**：右上角按钮或键盘 `M`
- 🎯 **难度选择**：简单 / 普通 / 困难 三档，本地记住偏好
- ✨ **粒子特效**：吃到食物时迸发出彩色彩屑
- 🎨 **覆盖层 UI**：暂停与结束统一视觉

## 🎮 操作说明

| 操作 | 键位 |
| --- | --- |
| 移动 | 方向键 / WASD |
| 暂停 / 继续 | 空格 / P |
| 静音 / 取消静音 | M |
| 重新开始 | 结束后回车，或点击「重新开始」按钮 |
| 移动端 | 屏幕方向键按钮 / 棋盘上下左右滑动 |

## 🛠 难度对照

| 难度 | 初始帧间隔 | 每档提速 | 升级节奏 | 最快 |
| --- | --- | --- | --- | --- |
| 简单 | 190 ms | 6 ms/档 | 每 60 分 | 90 ms |
| 普通 | 150 ms | 8 ms/档 | 每 50 分 | 60 ms |
| 困难 | 110 ms | 12 ms/档 | 每 35 分 | 45 ms |

## 🚀 本地运行

```bash
# 直接双击 index.html，或在浏览器中打开：
# file:///path/to/snake-game/index.html
```

也可起一个本地静态服务：

```bash
python -m http.server 8080
# 然后访问 http://localhost:8080
```
